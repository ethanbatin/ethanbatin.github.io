I am interested in software engineering because I want to learn how to create useful apps and websites. I hope to become proficient in programming languages such as Java and develop skills in areas like algorithms, data structures, and software design. I hope learning these skills will help me create functional and reliable software from ideas.

Beyond programming, I want to learn how to create assets such as art, animations, and music.

Overall, I hope to become a proficient and well-rounded software engineer through work and personal projects.
