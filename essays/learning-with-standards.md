## Learning with Coding Standards
Using coding standards has been relatively simple for me. From what I understand, most of the process involves downloading the necessary files provided and installing ESLint into the directory.
Once everything is set up correctly, the coding standards are not that difficult to use.
The main purpoe of coding standard is obviouly just to make sure the code follows a consistent style and there aren't any obvious problems or issues.

When first setting up coding standards for early assignments such as Bad Typescript, I was confused by the process. I remember having trouble getting ESLint to work correctly, and I was unsure really what the problem was.
Even now, today, I'm still not completely sure what the problerm was or why ESLint was not working properly at the time.
It was somewhat frustrating because I knew that I needed ESLint to work, that was the whole point of the assignments, but I didn't understand why the setup was not working when I thought I had followed the instructions correctly.

Since then though, I have become more comfortable with setting up the coding standards. I can set them up without much trouble now, and I understand the process better than I did when I first started.
I would absolutely say I don't completely understand everything about ESLint or how it works internally, but I understand enough to use it for the assignments.

## Conclusion
Overall, I think coding standards have been relatively easy for me to learn once I got past the initial setup. The most difficult part was getting ESLint working correctly during those first two assignments or so.
Now that I know how to set everything up, it feels pretty normal to do.
